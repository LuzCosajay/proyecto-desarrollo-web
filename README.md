# Proyecto Desarrollo de Aplicaciones Web

## Descripción
Aplicación web desarrollada con React y Vite que permite visualizar metas personales.

## Tecnologías utilizadas
- React
- Vite
- Bootstrap
- Sass

## Funcionalidades
- Visualización de metas
- Diseño responsive (desktop y mobile)
- Modal para agregar metas (diseño)
- Interfaz basada en el diseño proporcionado en clase

## Instalación y ejecución

1. Clonar el repositorio:
git clone <URL_DEL_REPOSITORIO>

2. Instalar dependencias:
npm install

3. Ejecutar el proyecto:
npm run dev

## Notas
Este proyecto corresponde a la Actividad 1 del curso Desarrollo de Aplicaciones Web.  
El enfoque principal fue la implementación del diseño proporcionado en clase.
