# Proyecto Desarrollo de Aplicaciones Web - Semana 1

## Descripción
Aplicación web desarrollada con React, Vite, React Bootstrap y Sass para la gestión de metas personales.

## Tecnologías utilizadas
- React
- Vite
- React Bootstrap
- Sass

## Funcionalidades
- Visualización de metas
- Formulario para agregar metas
- Diseño versión desktop y mobile
- Modal en versión mobile

## Instalación y ejecución

1. Clonar el repositorio:
```bash
git clone https://github.com/LuzCosajay/proyecto-desarrollo-web.git
```

2. Entrar a la carpeta del proyecto:
```bash
cd proyecto-desarrollo-web/semana1
```

3. Instalar dependencias:
```bash
npm install
```

4. Ejecutar el proyecto:
```bash
npm run dev
```
